# Covenant contracts

The SilverScript sources for the covenants whose compiled output is byte-pinned
into this package:

- `vault.sil` → `src/vault/template.ts` (fixtures: `scripts/vault-fixtures.json`)
- `escrow.sil` → `src/x402/escrow-template.ts` (fixtures: `scripts/escrow-fixtures.json`)

**These are reference copies.** sompi has no build-time or runtime dependency on
SilverScript — the templates are pinned bytes, verified against the fixtures in
`npm run smoke` (offline).

## Regenerating fixtures (only when a contract changes)

Fixtures are generated by the `vault-driver` Rust tool, which links the
SilverScript compiler. This is a one-off dev step; **nothing is ever pushed to
the SilverScript repo.**

1. In a local SilverScript checkout with `vault-driver/`, run
   `cargo build -p vault-driver`.
2. Use `vault-driver dump <agent> <owner> <max>` and
   `vault-driver escrow-dump <client> <server> <timeout>` to emit the compiled
   redeem script + arg encodings, and write the JSON fixtures consumed here.
3. Re-run `npm run smoke` — the template modules must reproduce the fixtures
   byte-for-byte, or the build fails.

If a contract's structure changes, update the segment constants in the
corresponding `*-template.ts` and bump the `*_TEMPLATE_VERSION`.
